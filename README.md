# 性能行情终端 · PerfTicker for macOS

**简体中文** | [English](README.en.md)

> 把 macOS「活动监视器」做成**炒股软件行情终端**：CPU / GPU / 内存 / 磁盘 / 网络……
> 每一项系统指标都是一只「个股」，实时 K 线、五档盘口、逐笔成交、自选行情一应俱全。
> 原生 Swift / AppKit，零外部依赖，单二进制双击即用。
>
> 作者 **QiuSui** · 组织 **QiuSui_Studio** · 开源协议 **GPL-3.0**

![界面预览](cover.png)

## 一、这是什么

传统活动监视器是「列表」；PerfTicker 把同样的数据搬到**证券行情终端**的界面语言里：

| 证券概念 | 对应系统指标 |
| --- | --- |
| 指数条（上证/深证/创业板） | CPU 综合指数、CPU 负载、GPU 负载、内存占用、GPU 显存、网络下行、进程数 |
| 自选股列表 | 可监测指标（含逐核占用） |
| 个股代码 | `000001`、`600519`… 每个指标都有交易所风格的代码 |
| K 线 | 以采样点为 tick，按 2s / 5s / 10s / 30s / 1min 聚合成 OHLC K 线；**红涨实心 / 绿跌实心**，含 MA5/10/20 与成交量 |
| 涨跌 / 涨跌幅 | 相对「今开」的变化；涨跌按各自单位显示（`+2.8pt`、`+0.4GB`） |
| 采样档位 | 0.5s / 1s / 2s / 5s / 10s |
| 五档盘口 · 主力动向 | 当前指标维度下的 Top 10 进程，带热度条与名次徽标 |
| 逐笔成交 | 进程启停、负载跳变、内存/负载告警、活跃进程成交流水 |
| 沪深个股列表 | 全量进程表：PID / 名称 / CPU% / 涨跌 / GPU% / 内存 / 线程 / 迷你 K 线；支持搜索、置顶、结束进程 |
| 跑马灯 | 全部指标的滚动快讯 |

**红涨绿跌** 遵循 A 股习惯，标题栏「红涨」按钮可一键切换为国际配色（绿涨红跌）。

## 三、设置 / 状态栏 / 关于

- **设置**：`开机自启动`（SMAppService 登录项）、`底部滚动信息`开关、`界面主题`三档（深色 / 浅色 / 跟随系统，实时监听系统外观切换），改动即时生效并自动保存。
- **关闭主窗口不会退出**：程序驻留状态栏，行情采样、经济结算继续在后台运行；右键菜单可 `打开主窗口` / `营收归零` / `退出`。
- **关于窗口**：开发者、组织、开源协议 GPL-3.0，底部附**运行环境**（macOS 版本/架构）、**硬件配置**（芯片/核心、GPU 核心数、内存、磁盘、网络）、**营收基准**折算系数。

## 四、桌面小挂件

标题栏「挂件」开关、状态栏右键菜单、主面板 `F9`，三种方式都能开关；位置与开关状态会记住。

- **拖拽任意空白处**移动，位置写回配置；
- **双击**挂件打开主面板；
- 右上「顶」= 总在最前（默认关，不抢你的前台窗口）；
- 不占 Dock、不进 `⌘+Tab`，可跨全部桌面空间显示。

## 五、交互

| 操作 | 说明 |
| --- | --- |
| 点击指数格 / 自选行 | 切换当前「品种」，主图、盘口、逐笔同步联动 |
| 点击 `2秒K`…`1分K` | 切换 K 线周期 |
| 鼠标悬停主图 | 十字光标 + OHLC / 涨跌 浮窗 |
| 点击「CPU / GPU / 内存」 | 进程表排序（再次点击反向） |
| 进程搜索框（或 `⌘F`） | 按进程名 / PID 过滤，`Esc` 清空 |
| 右键进程行 | 菜单：**结束进程**（二次确认）/ **置顶到榜首** |
| 滚轮 | 自选列表 / 进程表滚动 |

**快捷键**：`空格` 暂停/继续 · `1`-`5` K 线周期 · `E` 营收系统 · `⌘F` 进程搜索 · `T` 窗口置顶 · `C` 红涨/绿涨 · `F9` 挂件

窗口位置、大小、采样周期、配色、选中品种、排序方式会自动记忆（`~/Library/Application Support/PerfTicker/settings.json`）。

## 六、经济系统（算力经营）

标题栏「营收」开关（默认**关闭**，快捷键 `E`），开启后在图表下方划出**营收中心**专区：把每项占用率当成产能，
高负载持续越久赚得越多，空转则不断亏损。

| 经营单元 | 满载收益 | 盈亏平衡占用率 |
| --- | --- | --- |
| CPU 综合 | 22.0 元/s | 30% |
| GPU 引擎 | 30.0 元/s | 28% |
| 内存 | 12.0 元/s | 35% |
| 磁盘 IO | 7.2 元/s | 25% |
| 网络 | 7.2 元/s | 25% |

> 累计金额**固化在本地**（`settings.json` 的 `EcoTotal / EcoPeak / EcoSeconds`，按真实墙钟时间结算，每 15 秒与退出时落盘），
> 重启程序后继续累计；**开关「营收」只会暂停/恢复结算，不会清零**，只有面板左上「归零」按钮或状态栏菜单「营收归零」才会清零。
>
> **硬件自适应**：启动时探测本机芯片（性能核/能效核）、GPU 核心数、统一内存容量、固定磁盘数、系统版本，
> 按基准配置折算满载收益（限制在 0.3–4.0 倍之间），让不同设备在同一占用率下的收益可比。

结算规则（`Economy.NetOf`）：

```
净收益(元/s) = 满载收益 × (占用率/100)^1.7 − 空转成本
空转成本     = 满载收益 × (盈亏平衡点)^1.7
```

指数取 1.7 表示**边际递增**；系统热压力（`thermalState`）升高时 CPU 与 GPU 收益打折（过热降效），
暂停（`空格`）时营收停止结算。

## 七、性能与开销

- 隐藏/最小化窗口时停止全部重绘，仅保留采样与结算（心跳自动降频）；
- 自绘面板「按面板独立节拍重绘」，静态区域不重复绘制；
- K 线蜡烛与网格像素对齐、共享画笔/画刷；
- 诊断日志滚动写入 `~/Library/Application Support/PerfTicker/logs`。

## 八、数据口径

| 指标 | 采集方式 | 口径 |
| --- | --- | --- |
| CPU 占用 | `mach host_processor_info` | 逐核心 user+sys/total，整机取平均 |
| 内存 | `mach host_statistics64` + `sysctl vm.swapusage` | App内存/Wired/压缩 + 交换 |
| GPU 引擎占用 / 逐进程 GPU | IOKit `IOAccelerator` 性能统计 | Apple Silicon 统一内存口径 |
| 磁盘读写 | IOKit `IOBlockStorageDriver` | 字节/秒 |
| 网络上下行 | `getifaddrs`（优先 64 位计数器） | 字节/秒 |
| 进程 CPU / 内存 / 线程 | `libproc`（`proc_listallpids` / `proc_pidinfo`） | CPU% 为整机占比（0–100） |
| 热压力 | `ProcessInfo.thermalState` | Nominal/Fair/Serious/Critical 过热降效 |

> Apple Silicon 不对第三方开放实时频率与独立显存传感器，相应指数以占用率/热压力替代（已在界面注明）。
> 营收中心的磁盘/网络负载为**游戏化标定**：磁盘约 10MB/s、网络约 5MB/s 即视为满载产能，非真实 IO 饱和度。
> 所有采集均为**只读查询**，不需要管理员权限。

## 九、构建

需要 Xcode 15+ / Swift 5.9+：

```bash
swift build -c release
# 产物：.build/release/PerfTicker
```

```bash
./build_dmg.sh
```

## 十一、已知限制

- CPU/GPU **实时频率**与**温度**：Apple Silicon 不对第三方应用开放传感器，相应面板以占用率与热压力替代；
- 逐进程 GPU 占用依赖 IOAccelerator 统计，个别机型/系统版本可能无数据（显示 `—`）；
- 「开机自启动」依赖 SMAppService，需将 .app 安装到 `/Applications` 后注册最可靠。
